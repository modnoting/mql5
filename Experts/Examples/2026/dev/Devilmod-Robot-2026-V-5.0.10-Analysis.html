สรุปการทำงาน: EA นี้เป็นระบบ Martingale สำหรับทองคำ (XAUUSD) ที่มีระบบจัดการความเสี่ยงหลายชั้น รวมถึง Dynamic SL ตาม ATR, Trailing Stop, Circuit Breaker, Opposite Martingale (Recovery), Daily Profit/Loss Limit, Time Exit, และ Emergency Close โดยมี CSV Authentication สำหรับตรวจสอบสิทธิ์ผ่าน Google Sheets

สารบัญ

1. Martingale System - ระบบเพิ่ม Lot ทบ 2. Dynamic SL (ATR) - Stop Loss แบบปรับตามตลาด 3. Trailing Stop - ล็อคกำไรอัตโนมัติ 4. Adaptive Distance - ระยะห่างอัจฉริยะ 5. Circuit Breaker - ตัดไฟเมื่อขาดทุน 6. Trend Filter (EMA) - ตัวกรองแนวโน้ม 7. Trading Hours Filter - จำกัดเวลาเทรด 8. CSV Authentication - ตรวจสอบสิทธิ์ 9. Opposite Martingale - Recovery กลับทิศ 10. Daily Profit Limit - หยุดเมื่อกำไรถึงเป้า 11. Daily Loss Limit - หยุดเมื่อขาดทุนเกินลิมิต 12. Time Exit - ปิดเมื่อถือนานเกิน 13. Emergency Close - ปิดฉุกเฉิน เงื่อนไขการเปิด Order (Entry) ลำดับการทำงาน OnTick ตัวแปร/ระบบที่ไม่ได้ใช้งาน

ตัวอย่าง:

วิธีทำงาน:
• เมื่อกำไรของ BUY > 2500 จุด → เลื่อน SL ขึ้นมาอยู่ใต้ราคา Bid 2500 จุด
• เมื่อกำไรของ SELL > 2500 จุด → เลื่อน SL ลงมาเหนือราคา Ask 2500 จุด
• ระบบจะ Trail ทุก order ที่ไม่ใช่ RECOVERY
• เรียกใช้ทุก tick ผ่าน TrailingAlls()

วิธีทำงาน (เมื่อเปิด):

แนะนำ: เปิดใช้เฉพาะเมื่อต้องการเทรดตามแนวโน้มเท่านั้น

9. Opposite Martingale (Recovery) ON

รายละเอียดข้อมูล
สถานะใช้งานอยู่
ตัวแปรควบคุมUseOppositeMartingale = true
Trigger Point2000 จุด (OppositeTriggerPts)
Max Lot2.0 (OppositeMaxLots)
Max Layers5 (OppositeMaxLayers)
Cooldown600 วินาที (10 นาที)
คำสำคัญใน Comment"RECOVERY"
ตำแหน่งโค้ดCheckOppositeMartingale() บรรทัด 400-514
วิธีทำงาน:
1. ตรวจสอบว่ามี position เปิดอยู่ ≥ 3 ตำแหน่ง
2. คำนวณกำไร/ขาดทุนรวมของแต่ละทิศ (BUY / SELL)
3. ถ้า BUY ขาดทุน ≥ 2000 จุด และยังไม่มี SELL → เปิด SELL RECOVERY
4. ถ้า SELL ขาดทุน ≥ 2000 จุด และยังไม่มี BUY → เปิด BUY RECOVERY

Lot ของ Recovery: คำนวณจาก Martingale formula แต่จำกัดไม่เกิน OppositeMaxLots (2.0)
จุดประสงค์: เป็นกลยุทธ์ hedge เพื่อ recover เมื่อ Martingale หลักขาดทุนลึก โดยเปิด position ตรงข้ามเพื่อ "จับ" การกลับตัวของราคา

10. Daily Profit Limit ON

รายละเอียดข้อมูล
สถานะใช้งานอยู่
ตัวแปรควบคุมUseDailyProfitLimit = true
Profit Target$500 (DailyProfitTarget)
Buffer$100 (DailyProfitBuffer)
ตำแหน่งโค้ดCheckDailyProfitLimit() บรรทัด 620-664
วิธีทำงาน:
• ทุกวันจะบันทึก Balance เริ่มต้น (g_dailyStartBalance)
• ถ้า Balance ≥ Balance เริ่มต้น + $500 และไม่มี position → หยุดเทรด
• ถ้า Equity ≥ Balance เริ่มต้น + $600 ($500+$100 buffer) และมี position → ปิดทุก position แล้วหยุด

กลไก: Buffer $100 ช่วยให้ปิด position ได้ทันก่อนที่กำไรจะกลับลงมา (เช่น ถ้า Equity ถึง $600 แต่กำลังจะกลับลง → ปิดก่อน)

11. Daily Loss Limit ON

รายละเอียดข้อมูล
สถานะใช้งานอยู่
ตัวแปรควบคุมUseDailyLossLimit = true
Loss Limit$500/วัน (DailyLossLimit)
ตำแหน่งโค้ดCheckDailyLossLimit() บรรทัด 669-690
วิธีทำงาน:
• ทุกวันจะบันทึก Balance เริ่มต้น (ใช้ร่วมกับ Daily Profit Limit)
• คำนวณ DailyPnL = Balance ปัจจุบัน - Balance เริ่มต้น
• ถ้า DailyPnL < -$500 → ปิดทุก position ทันที

สำคัญ: ระบบนี้ปิด position เลย ไม่ใช่แค่หยุดเทรด (ต่างจาก Circuit Breaker)

12. Time Exit ON

รายละเอียดข้อมูล
สถานะใช้งานอยู่
ตัวแปรควบคุมUseTimeExit = true
เวลาถือสูงสุด240 นาที (4 ชั่วโมง)
ตำแหน่งโค้ดCheckTimeExit() บรรทัด 695-719
วิธีทำงาน:
• ตรวจสอบทุก position ที่ไม่ใช่ RECOVERY
• คำนวณเวลาที่ถือ = (เวลาปัจจุบัน - เวลาเปิด) / 60 นาที
• ถ้าถือเกิน 240 นาที → ปิด position นั้นทันที

จุดประสงค์: ป้องกัน position ที่ "ติด" อยู่นานเกินไป (เช่น เปิด BUY แล้วราคาไหลลง จนต้องรอ Martingale หลายชั้น)

ลำดับการทำงาน OnTick

1. ตรวจสอบ CSV Authentication → ถ้าล้มเหลว → หยุด
2. ตรวจสอบ Daily Profit Limit → ถ้าถึงเป้า → หยุด
3. ตรวจสอบ Daily Loss Limit → ถ้าเกินลิมิต → ปิดทุก position → หยุด
4. ตรวจสอบ Free Margin < 0 → ถ้าติดลบ → ปิดทุก position → หยุด
5. ดึงค่า Indicators (MACD M1, Stoch M5, RSI H1, EMA50/200)
6. ตรวจสอบ Trading Hours → ถ้านอกเวลา → หยุด (ถ้าไม่มี position)
7. เรียก TrailingAlls() → เลื่อน SL สำหรับทุก position ที่มีกำไร
8. เรียก CheckOppositeMartingale() → ตรวจสอบ Recovery
9. เรียก CheckTimeExit() → ปิด position ที่ถือเกิน 240 นาที
10. ตรวจสอบ Circuit Breaker → ถ้า loss > 5% equity → หยุดเทรด
11. นับจำนวน orders ที่เปิดอยู่
12. ตรวจสอบว่าราคาเคลื่อนที่สวนทางพอ → ตั้ง flag gi_340 = true
13. ถ้า gi_340 = true → เปิด Martingale order ใหม่
14. ถ้าไม่มี position → ตรวจสอบ Entry Signals (Stoch + MACD + RSI)
15. ถ้ามี signal → เปิด order แรก
16. คำนวณ Weighted Average Price ของทุก position
17. ปรับ SL/TP ของทุก position ตาม Weighted Average Price
