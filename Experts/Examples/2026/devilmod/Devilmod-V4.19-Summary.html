สิ่งที่เปลี่ยนแปลง

1. Trailing Stop - ปรับปรุงครั้งใหญ่

舊
V4.16: ทำ Trailing Stop เฉพาะ order แรก เท่านั้น
新
V4.19: ทำ Trailing Stop กับทุก order ที่มีกำไรพอ
เดิม: ปิด SL ให้เฉพาะ order เก่าสุดตัวเดียว
ใหม่: → ปิด SL ให้ ทุก order ที่ราคาห่างจาก Entry >= TrailingPoints

ผลลัพธ์: ทุก order ที่มีกำไรจะถูก lock กำไรไว้ ไม่ใช่แค่ตัวแรก

2. Runaway Recovery System

ระบบกู้คืนเมื่อราคาหลุด — ถูกเรียกจาก ManageMarginRisk() ทุก tick

เงื่อนไข:
1. → ครบทุก MaxTrades (เช่น 15/15)
2. → ราคาห่างจาก order สุดท้าย >= RecoveryDistancePoints
3. → Cooldown 300 วินาที

การทำงาน: ปิด order เก่าสุด ที่กำลังขาดทุน เพื่อลดความเสี่ยง

ระบบการทำงานทั้งหมด (V4.19)

  1. Entry Signal — 3-Layer (Trend + Momentum + Price Action)
  2. Martingale Open — เปิด Order ใหม่เมื่อราคาห่าง >= MartingaleDistancePoints
  3. Runaway Close — ปิด Order เก่าสุดเมื่อครบทั้ง MaxTrades + ราคาไหลเกิน TriggerDistance
  4. Trailing Stop — เลื่อน SL สำหรับ ทุก Order เมื่อกำไร >= TrailingPoints
  5. UpdateMartingaleTP — ตั้ง TP เท่ากันทุก Order จาก Weighted Average
  6. Runaway Recovery — ปิด Order เก่าสุดเมื่อ MaxTrades + ราคาห่างเกิน RecoveryDistancePoints
  7. Margin Critical — ปิดทั้งหมดเมื่อ Margin >= 90%

Flow การทำงาน (OnTick)

1. ตรวจสอบ CSV Authentication
2. Display_Info() — แสดงผลบนหน้าจอ
3. CheckDailyLimits() — ตรวจสอบ Daily Loss / Profit Target
4. ManageMarginRisk() — ทำงานทุก tick
    ├── Margin Critical → ปิดทั้งหมด
    ├── Price Runaway Detection
    ├── Runaway Close (เมื่อ MaxTrades + ราคาไหล)
    └── Runaway Recovery (ปิด order เก่าสุด)
5. ตรวจสอบเวลา (วัน/ชั่วโมง)
6. ตรวจสอบ Bar ใหม่
7. TrailingStopFirstOrder() — ทำกับทุก order
8. UpdateMartingaleTP() — ตั้ง TP ใหม่
9. ตรวจสอบ Entry Signal
10. เปิด Order ใหม่ (ถ้ามีสัญญาณ)
