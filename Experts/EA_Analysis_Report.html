2. ระบบ Entry Signal (Scoring System)

ใช้ระบบให้คะแนนจาก 4 เงื่อนไข ต้องมีคะแนน ≥ MinConfirmation (3) และ Trend ต้องสอดคล้อง

3. ระบบ Risk Management

  • Stop Loss: 1500 points (15 pips สำหรับ 5 _digits)
  • Take Profit: 2250 points (22.5 pips)
  • Lot Size: 0.05 (คงที่)
  • Max Spread: 300 points (ป้องกัน spreads สูง)
  • Trailing Stop: เริ่มที่ 800 points, Step 150 points

4. ระบบ Time Filter

เปิดเทรดเฉพาะช่วง 08:00 - 20:00 (เวลาท้องถิ่น) เพื่อหลีกเลี่ยงช่วงตลาดเงียบ

❌ ส่วนที่ไม่ใช้งาน / ข้อจำกัด

1. ฟังก์ชัน RSI Divergence (ไม่ถูกเรียกใช้)

bool CheckRSIBullishDivergence() { ... }
bool CheckRSIBearishDivergence() { ... }

⚠️ มีการสร้างฟังก์ชันไว้แต่ไม่ได้เรียกใช้ใน GetEntrySignal()

2. Dynamic Lot Sizing

ไม่มีการคำนวณ Lot แบบ % Risk ต่อเทรด ใช้ Lot คงที่ 0.05 ซึ่ง:

  • ไม่เหมาะกับพอร์ตทุนต่างกัน
  • ไม่มีการปรับตาม volatility

3. ระบบ Close Position

ไม่มีระบบปิด position อัตโนมัติ (Partial close, Break-even, Emergency close)

4. ข้อควรระวัง

  • Timeframe M1: เหมาะสำหรับ Scalping แต่อาจมีสัญญาณหลอกจำนวนมาก
  • Stochastic ซ้ำซ้อน: สร้าง handleStochMain และ handleStochSignal แต่ใช้ indicator ตัวเดียวกัน (ควรใช้ตัวเดียว)
  • Order Filling: ใช้ ORDER_FILLING_FOK ซึ่งอาจไม่เหมาะกับทุก broker

📈 สรุปการไหลเวียนของโปรแกรม

OnInit()
├── สร้าง CTrade object
├── สร้าง Indicator Handles (EMA, RSI, Stoch, Momentum)
└── ตรวจสอบ handle validity

OnTick() (เรียกทุก tick)
├── ตรวจสอบ Time Filter (ถ้าเปิดใช้)
├── ตรวจสอบ New Bar (M1)
├── ManageTrailingStop() (ถ้าเปิดใช้)
├── GetEntrySignal() → return 1 (Buy), -1 (Sell), 0 (No signal)
│ ├── ดึงค่า indicators shift 1-2
│ ├── คำนวณ buyScore/sellScore จาก 4 เงื่อนไข
│ └── ตรวจสอบ MinConfirmation ≥ 3 + Trend
└── ExecuteBuy() / ExecuteSell() ถ้ามีสัญญาณ
├── ตรวจสอบ HasOpenPosition()
├── ตรวจสอบ Spread
├── คำนวณ Lot, SL, TP
└── ส่ง Order ผ่าน CTrade

💡 ข้อเสนอแนะในการปรับปรุง

  1. ใช้ Stochastic ตัวเดียวแทน 2 ตัวที่ซ้ำกัน
  2. เพิ่มระบบ Dynamic Lot Size ตาม % Risk
  3. เรียกใช้ฟังก์ชัน RSI Divergence ที่เขียนไว้แล้ว
  4. เพิ่มระบบ Break-even อัตโนมัติ
  5. พิจารณาเปลี่ยน ORDER_FILLING_FOK เป็น ORDER_FILLING_IOC หรือ RETURN
  6. เพิ่ม backtesting report output
